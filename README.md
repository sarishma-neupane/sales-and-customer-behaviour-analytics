### E-Commerce Sales & Data Analytics Project

This project looks at a retail company's sales data from start to finish. I used Python to clean up the messy raw data, moved it into a SQL database to run advanced business queries, and built an interactive Power BI dashboard to visualize the results. 

### What is Inside This Project?

* **ecommerce_sales_dashboard.pbix** - My final Power BI dashboard where you can click around and see charts of our sales.
* **Project2.ipynb** - The Python notebook where I cleaned the data and sent it automatically to SQL.
* **project2..sql** - The SQL file where I wrote code to answer major business questions.
* **ecommerce_sales_raw.csv & cleaned1.csv** - The raw and final datasets showing orders, prices, regions, and shipping times.

### Top Business Insights I Discovered:

* **Best Sales Month:** June is by far the strongest month for the business, bringing in over 147 million in revenue.
* **Top Product:** Home Theater Systems are the biggest moneymakers for the company.
* **Top City:** Customers in Mumbai spend the most money, contributing over 89 million in sales.
* **Payment Choice:** Most shoppers prefer using their Mobile Wallet to pay for things (used in 572 orders).

### Tools & Skills Used:

* **Python** (Pandas library) - For clearing duplicates and fixing messy text.
* **SQL** (MySQL) - For organizing tables and calculating totals.
* **Power BI** - For building the visual dashboard and charts.
